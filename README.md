# AERO ECHO · 裂空回响

[立即试玩](https://sky19840308.github.io/aero-echo-h5/) · [账户与双人协作版](https://aero-echo-sky.spy-liver.chatgpt.site/game)

Build 15：简体中文、日本語、English；9 章、27 关、3 位飞行员、9 位 Boss。

- 12 张原图机体外观，每架战机 4 种，原生比例与透明边缘。
- 登录账户独立云存档、昵称和冲突选择。使用 ChatGPT 登录；未配置直接 Google 登录。
- 两个不同账户可以用 8 位房间码在线协作，房主开始，双方暂停同步。
- 协作始终从第一章基础机开始，不消耗、不修改单人永久进度。大章结束存活者获得 2 点临时强化；死亡清空，观战至下一大章基础复活；双人阵亡结束。
- 通关结局：4 分 30 秒三语滚动字幕与返航画面，5 秒黑场，20 秒彩蛋；支持暂停、重播及跳过。

GitHub 版仍可离线使用本地存档。云存档与协作请进入账户版；旧存档只在明确确认导入后迁移。

拖拽或 WASD/方向键移动。Q 主动技、E 爆弹、空格终极技、P 暂停；手机支持触摸按钮。

## 发布校验

工作流恢复 SHA256 校验的不可变 Build 13 媒体，应用本提交的运行代码与素材，重建 12 皮肤清单，并核对 `runtime-build15.sha256` 全部运行文件。账户 API 与数据库由账户版服务器提供，不包含在 GitHub Pages 中。

真实 SQLite 后端、账户隔离、27 关/9 Boss 联机模拟、原图像素、Native Canvas 绘制、三语界面与资源故障恢复已有自动化检查。自动化检查不等于两台真实手机的公网联机或扬声器试听。
正式结局采用《最终章 · 黎明之后》全文与三机动态返航。可通过游戏地址后加 `?ending=1` 预览，不产生奖励。
