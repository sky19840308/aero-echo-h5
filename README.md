# AERO ECHO · 裂空回响

[立即试玩](https://sky19840308.github.io/aero-echo-h5/) · [账户与双人协作版](https://aero-echo-sky.spy-liver.chatgpt.site/game)

Build 27：简体中文、日本語、English；9 章、27 关、3 位飞行员、9 位 Boss。

- 每位飞行员出击有 3 条命；受击失去 1 条命并获得短暂无敌，命数补给可以恢复生命。界面不再显示玩家生命或护盾血条。
- 三位英雄各有四姿态动态炸弹演出；启动时清除敌弹、攻击全场普通敌机并削弱 Boss，返场后获得 5 秒无敌。召唤画面用 Yuji Syuku 笔刷字体逐字显示「三段撃」「風林火山」「忍術皆伝」与英雄名「織田信長」「武田信玄」「服部半蔵」，并叠加墨迹、辉光和朱印；普通技能不会显示艺术字。
- 第一技能只展示战斗特效，不再弹出称号文字；曙光-7喷发等离子激光并加速弹丸，堡垒-3使用全伤害免疫护盾与两颗环绕卫星，幽蓝-X隐身无敌并自动连斩。
- 敌方激光拥有至少 1.6 秒宽幅预警；普通敌机交替发射更快的高速与慢速弹。波次加入编队、无规则变轨和红色航线预警的俯冲撞击型敌机。
- 敌机耐久、机动、弹速和瞄准随难度提升；复杂难度增加约 34% 的每波敌机，降低敌弹密度、射击频率与 Boss 技能频次，为躲避留出空间。常规资源掉落大幅减少，炸弹携带上限固定为 5 枚。
- 玩家受击后有着火坠毁与返场动画；重型、精英及部分普通敌机被击毁后会坠毁爆炸。
- 全新火力、机动、生存三路线天赋树共 18 点；节点按前置关系解锁，并用统一的可点亮组件展示。旧天赋等级会转换为可重新分配的点数。
- 每次被击坠后返场获得完整 5 秒无敌，计时在坠毁动画结束后开始。
- 保留拖拽、WASD / 方向键移动、Q 主动技、E 爆弹、空格终极技、P 暂停；手机支持触摸按钮。
- 12 款机体外观，每架战机 4 款。支持账户云存档、昵称、冲突选择和双人在线协作；协作飞行员各有 3 条命，归零后观战，可在下一大章开始时复活。
- 通关结局支持三语字幕、返航画面、暂停、重播和跳过。

GitHub Pages 版可以离线使用本地存档。云存档与在线协作请进入账户版；导入旧存档前会先预览并要求确认。

## 发布校验

工作流恢复 SHA256 校验的不可变 Build 13 媒体，叠加 Build 27 代码与英雄动画，重建皮肤清单，再核对 `runtime-build27.sha256` 中的全部运行文件。部署前执行命数、复杂难度、技能、炸弹、天赋树与协作测试、原生 Canvas 特效测试及武器阶段回归。

回归测试：`tests/lives-bombs.mjs` 校验命数、敌机难度、爆弹和协作状态；`tests/build27-combat.mjs` 校验战斗、逐字炸弹艺术字、敌机行为与返场保护；`tests/talent-tree.mjs` 校验旧存档迁移、节点解锁、平衡效果和复杂难度弹幕；`tests/weapon-phases.mjs` 使用原生 Canvas 校验弹幕预警、冲击特效和动画图集帧裁切。
