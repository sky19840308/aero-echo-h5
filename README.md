# AERO ECHO · 裂空回响

[立即试玩](https://sky19840308.github.io/aero-echo-h5/) · [账户与双人协作版](https://aero-echo-sky.spy-liver.chatgpt.site/game)

Build 24：简体中文、日本語、English；9 章、27 关、3 位飞行员、9 位 Boss。

- 每位飞行员出击有 3 条命；受击失去 1 条命并获得短暂无敌，命数补给可以恢复生命。界面不再显示玩家生命或护盾血条。
- 三位英雄各有四姿态动态爆弹演出；启动时清除敌弹、攻击全场普通敌机并削弱 Boss，返场后获得 5 秒无敌。
- 敌方与 Boss 弹幕数量和速度均已降低。难度不再增加敌机数量、弹数或 Boss 生命；精英难度主要增加机动和瞄准能力。
- 保留拖拽、WASD / 方向键移动、Q 主动技、E 爆弹、空格终极技、P 暂停；手机支持触摸按钮。
- 12 款机体外观，每架战机 4 款。支持账户云存档、昵称、冲突选择和双人在线协作；协作飞行员各有 3 条命，归零后观战，可在下一大章开始时复活。
- 通关结局支持三语字幕、返航画面、暂停、重播和跳过。

GitHub Pages 版可以离线使用本地存档。云存档与在线协作请进入账户版；导入旧存档前会先预览并要求确认。

## 发布校验

工作流恢复 SHA256 校验的不可变 Build 13 媒体，叠加 Build 24 代码与新英雄动画，重建皮肤清单，再核对 `runtime-build24.sha256` 中的全部运行文件。

回归测试：`tests/lives-bombs.mjs` 校验命数、难度、爆弹和协作状态；`tests/weapon-phases.mjs` 使用原生 Canvas 校验弹幕预警、冲击特效和动画图集帧裁切。
